ARIS3 / aris3_task_manager
==========================

[폴더 역할]
Pick & Place 작업 순서 관리

[개발 기술]
C++17 / rclcpp / ROS 2 Action

[구현할 내용]
물체 선택, 목표 좌표 확인, 경로 계획 요청, 접근·집기·이동·놓기 단계 실행; 실패 시 정지·복귀 및 작업 상태 발행

[완료 기준]
하나의 작업 명령으로 시뮬레이션에서 Pick & Place 시퀀스를 검증할 수 있다.

[개발 단계]
PHASE 4 ~ 5

[현재 상태]
1차 구현 완료 (2026-11-07, Gazebo 작업 셀 e0509_sim 위에서 검증)
- ExecuteTask 액션 서버 + 상태 머신: VALIDATE → OBSERVE → PERCEIVE → PLAN → PICK → PLACE → VERIFY, 실패 시 RECOVER
- 경로 계획은 두산 서비스(move_line, ikin/fkin) 사용. MoveIt 연결은 RobotClient 교체로 확장 예정
- 사용법·구조: README.md / 원리와 공부할 것: docs/ARIS3_TaskManager_학습가이드.md

[참고]
- ARIS3의 첫 번째 목표는 Gazebo 물리 실행 중 E0509 관절 제어 성공이다.
- 최상위 README.md는 이후 작성한다.

ARIS3 / aris3_gui
=================

[폴더 역할]
ARIS3 Control Station - 하나의 Qt 화면에서 시뮬레이션·실물 로봇의 상태 확인, 작업 실행, 음성 명령, 카메라, 수동 조작

[개발 기술]
Python / PyQt5 / rclpy  (2026-11-08 결정: 기존 e0509_manual/gui.py(PyQt5)와 안전 코드를 재사용하기 위해 C++ 대신 Python)

[구현할 내용]
마스터플랜 07장 목업 배치: 시스템·로봇·그리퍼 상태, 카메라 Top View + 검출 표시, 작업 큐·단계 진행, 로그,
음성 명령(누르고 말하기 / 문장 입력, aris3_voice 노드), 수동 조작(TCP·관절), 정지. RViz 3D 내장은 도전 과제

[완료 기준]
GUI 하나로 시뮬레이션을 시작하고 음성 또는 버튼으로 Pick & Place 를 실행·감시할 수 있다.
GUI 를 꺼도 로봇 핵심 노드(Task Manager, MoveIt, 음성)는 독립적으로 동작한다.

[개발 단계]
CHALLENGE (Windows MARK1 PC 를 쓰지 않기로 하면서 통합 관제 화면으로 범위 확대)

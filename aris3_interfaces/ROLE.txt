ARIS3 / aris3_interfaces
========================

[폴더 역할]
ARIS3 노드 공통 통신 규격

[개발 기술]
ROS 2 msg / srv / action

[구현할 내용]
검출 물체 정보, 대상 색상·도형, 작업 요청 및 진행 상태 등 공통 메시지·서비스·액션 정의; C++ 및 Python 노드가 동일 인터페이스 사용

[완료 기준]
모듈 간 통신 데이터 형식이 정의되어 C++ 및 Python 노드에서 동일하게 사용할 수 있다.

[개발 단계]
연동 단계에서 단계별 추가

[현재 상태]
1차 정의 (2026-11-07): msg DetectedObject, DetectedObjectArray, TaskStatus / srv GripperCommand (OPEN, CLOSE, STATUS) / action ExecuteTask
- 이름·필드는 설계 문서 4장의 후보 계약을 따름. 바꾸면 사용하는 모든 패키지를 다시 빌드할 것
추가 (2026-11-08): msg VoiceCommand (/aris3/voice_command, aris3_voice -> GUI)
추가 (2026-11-13): DetectedObject 에 height_mm·level (깊이로 계산한 쌓인 층, 0 = 모름)
추가 (2026-11-13): DetectedObject 에 grasp_u·grasp_v (쌓인 큐브 원근 보정 픽셀, 0 = 채우지 않음 -> pose.position 사용)
변경 (2026-11-14): RealCalibration REMEMBER 가 탁자 블록 마커(ArUco)를 먼저 씀, AUTO_RECORD=6 추가 (로봇이 블록을 잡아 보정점)
추가 (2026-11-13): VoiceCommand 에 target_color (쌓기 받침 색), RealPickPlace 에 PICK_AND_STACK=6
추가 (2026-11-14): VoiceCommand 에 number·target_number (큐브 번호 - 「1번 파란색 큐브」, 0 = 말하지 않음). 낸 곳 aris3_voice, 받는 곳 aris3_gui_cpp
추가 (2026-11-14): RealPickPlace 에 PLACE_ON=7 (들고 있는 큐브를 받침 큐브 위에 놓기), VoiceCommand action 에 "find" (색 큐브 찾기),
  action "place" + target_color = 올려놓기 (받침 색)
추가 (2026-11-09): msg HandGesture (/aris3/gesture), ExecuteTask 에 target_id·place_position, VoiceCommand 에 home·지시어
추가 (2026-11-10, 실물 로직을 aris3_real_bridge 노드로 옮기기 위한 계약 - 두 GUI(PyQt, ARIS C++)가 같이 씀):
  msg RealRobotState (/aris3/real/state), srv RealCalibration (/aris3/real/calibration),
  action RealMotion (/aris3/real/motion), action RealPickPlace (/aris3/real/pick_place),

  접속·정지·조작 허용·손으로 움직이기는 std_srvs (Trigger / SetBool): /aris3/real/connect, disconnect, stop, set_armed, set_hand_guide

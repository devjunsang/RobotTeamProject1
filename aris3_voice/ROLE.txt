ARIS3 / aris3_voice
===================

[폴더 역할]
음성 명령 인식 및 구조화

[개발 기술]
Python / faster-whisper (Whisper STT) / rclpy

[구현할 내용]
마이크 또는 녹음 파일의 한국어 명령 인식; 색상·도형·행동을 공통 작업 명령으로 변환; C++ 작업 관리자에 ROS 2 메시지로 전달

[완료 기준]
빨간 삼각형을 집어줘 같은 명령이 올바르게 해석되어 작업 관리자에 전달된다.

[개발 단계]
PHASE 5

[현재 상태]
1차 구현 (2026-11-08): voice_node (arecord + faster-whisper base, VAD) -> /aris3/voice_command.
MARK1 command_parser 를 옮겨 '색 필수·도형 선택'·노랑·큐브 표현 추가 (pytest 12/12).
Windows MARK1 PC 는 쓰지 않고 GUI 의 '누르고 말하기' 버튼(/aris3/voice/listen)으로 녹음한다.
faster-whisper 는 가상환경(~/venvs/mark1_voice)에 설치, launch 가 그 Python 으로 실행
2026-11-10: 음성 명령 모드 - GUI ON/OFF 버튼(/aris3/voice/active)으로 켜 두면 계속 듣다가 말 한 마디씩 잘라
인식하고, 「아리스(ARIS)」 로 시작하는 말만 명령으로 낸다 (예: 「아리스 빨간 도형 잡아」). 호출어가 없으면 무시.
Whisper 가 다르게 적는 형태(알리스·아리수·아리스야·ARIS)도 받음. 직접 친 문장은 호출어 없이도 받음.
2026-11-11: 「아리스」 만 말하고 쉬었다가 명령해도 받음 (WakeGate: 부른 뒤 8 초 안의 다음 말 하나).
  명령 추가: 멈춰(stop, 무엇보다 먼저) · 계속해(resume) · 연결해제(disconnect) · 가동(power_on).
2026-11-11: LLM 해석 (llm_parser.py, Claude Haiku 5.5, effort low, JSON 스키마 강제) - 「멈춰」 는 낱말 표로 바로,
  나머지는 LLM 먼저 -> 키 없음·시간 초과(4 초)·오류면 낱말 표. 둘이 다르게 읽으면 「해석 차이」 로그.
  키: ANTHROPIC_API_KEY (음성 가상환경 ~/venvs/mark1_voice 에 anthropic 패키지 설치). 끄기: llm:=false.
  pytest 6개 (키 없이) + 실제 API 10개 (키 있을 때만).
listening.py (strip_wake_word, UtteranceSegmenter - 적응형 소음 문턱) pytest 7개 추가 (전체 32).
누르고 말하기(/aris3/voice/listen)는 예전 호환용으로 남김.
2026-11-11: ARIS 목소리 (speaker.py) - ARIS 화면이 정한 대답(/aris3/voice/say)을 edge-tts 세라피나 음성으로,
  노트북 내장 스피커로 말한다 (블루투스 기본 출력 무시). 「아리스」 만 부르면 「네, 말씀하세요.」
2026-11-12: 인식률 개선 - Whisper large-v3-turbo GPU (안 되면 CPU base), 명령 낱말 미리 알림(stt_prompt),
  잘못 적힌 호출어(아래스·RS)·정지(먹쳐·멈쳐) 받기, ARIS 가 말하는 중 녹음된 말은 문장 중간 호출어도 찾음,
  LLM 프롬프트에 실제 오인식 예(혐의로->홈) 추가. pytest 53개 (+ 실제 API 10개). 자세한 설명은 README.md.

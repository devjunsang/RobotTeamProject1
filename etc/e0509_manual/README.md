# e0509_manual — E0509 수동 컨트롤러

버튼을 한 번 누를 때마다 로봇이 **정해진 만큼만** 움직이는 화면입니다. 화면의 `접속` / `접속 끊기` / `재접속` 버튼으로 실제 로봇 연결(두산 bringup)도 직접 켜고 끕니다.

## 설치 (팀원 PC)
필요한 것: Ubuntu 24.04 + ROS 2 Jazzy, 같은 워크스페이스에 빌드된 `doosan-robot2`(jazzy 브랜치: `dsr_msgs2`, `dsr_bringup2`), `python3-pyqt5`.
```bash
cd ~/ros2_ws/src && unzip ~/Downloads/e0509_manual.zip      # e0509_manual/ 폴더가 생김
sudo apt install python3-pyqt5
cd ~/ros2_ws && colcon build --packages-select e0509_manual && source install/setup.bash
python3 src/e0509_manual/test_gripper_drl_mock.py           # 로봇 없이 그리퍼 코드 점검 (ALL PASS)
```
로봇 네트워크: 컨트롤러 `110.120.1.66`, 포트 12345. PC 유선 랜을 `110.120.1.x/24` 고정 IP로 설정합니다.
**PC마다 다른 x를 쓰세요** (이 문서를 만든 PC가 `.50`). **로봇에는 한 번에 한 PC만 접속**하세요. 접속하면 제어 권한을 가져갑니다.

## 실행

**화면만 띄우고, 접속은 버튼으로** (권장)
```bash
ros2 run e0509_manual manual_controller                 # 오른쪽 위 「접속」 버튼 → 확인 창 → 접속
ros2 run e0509_manual manual_controller --host <IP> --rviz false
```

**화면 + 바로 접속** (로봇 옆에 사람이 있을 때만)
```bash
ros2 launch e0509_manual real.launch.py                 # 컨트롤러 IP 110.120.1.66, RViz 포함
ros2 launch e0509_manual real.launch.py host:=<IP> z_min:=50 rviz:=false
```
접속하면 두산 코드가 **서보를 켜고, 펜던트의 제어 권한을 가져오고, 자동 모드로 바꿉니다.** 팔은 움직이지 않습니다.
창을 닫거나 터미널에서 Ctrl-C를 누르면 이 화면이 연 접속도 끊습니다.

에뮬레이터 등 다른 이름의 bringup에 붙어 보기만 할 때: `ros2 run e0509_manual manual_controller --ns e0509_sim_test --z-min 0`
(접속 버튼은 실제 로봇용입니다.)

## 접속 / 접속 끊기 / 재접속
| 버튼 | 하는 일 |
|---|---|
| `접속` | 컨트롤러에 닿는지 먼저 확인한 뒤 두산 bringup을 실행. 로봇이 `대기(STANDBY)`가 되면 그리퍼 상태를 자동으로 읽음 |
| `접속 끊기` | 움직이는 중이면 먼저 정지 → bringup 종료. **로봇 서보가 꺼짐**(브레이크가 팔을 잡음) |
| `재접속` | 끊기 → 약 10초 대기 → 접속. 그리퍼가 응답하지 않을 때 이것으로 풀림 |

- 세 버튼 모두 확인 창이 뜹니다. 기본 선택은 `No`입니다.
- 터미널에서 따로 띄운 bringup(`name:=e0509_real`)도 찾아서 끊을 수 있습니다(`다른 곳에서 실행한 접속`으로 표시).
- **끊으면 그리퍼 전원도 함께 꺼지는 것으로 보입니다.** 재접속 뒤 그리퍼 설정이 전원을 켰을 때의 값으로 돌아가 있고 토크가 꺼져 있었습니다. 잡고 있는 물건은 먼저 내려놓으세요.
- 끊은 직후 바로 다시 접속하면 두산 드라이버가 실시간 연결에 실패하며 죽을 수 있습니다(2초 간격에서 실제로 발생). 그래서 끊은 뒤 최소 10초를 기다렸다가 접속하고, 그래도 드라이버가 죽으면 한 번 자동으로 다시 시도합니다.
- bringup 기록: `/tmp/e0509_manual_bringup_e0509_real.log`

## 화면 사용법
1. 오른쪽 위 `접속`을 누르고(확인 창에서 `Yes`), `관절 각도 수신 중`, `대기 (STANDBY)`가 보이는지 확인합니다.
2. **조작 허용**을 체크합니다. 체크하지 않으면 버튼이 잠겨 있습니다. 2분 동안 명령이 없으면 다시 잠깁니다.
3. **관절 이동**: J1–J6의 `−` / `+`. `한 번에`(1–10°)와 `속도`(5–30°/s)를 고릅니다.
4. **좌표 이동**: 손끝(TCP)을 로봇 받침 기준 X/Y/Z로 `한 번에`(1–20 mm)만큼 직선 이동합니다. 손목 방향은 그대로입니다.
5. **그리퍼**: 아래 그리퍼 패널에서 `열기` / `닫기 (잡기)` / `목표 위치로`(0~740) / `힘 풀기`. `잡는 힘`(150/300/500 mA)과 `속도`를 고릅니다. `상태 읽기`는 조작 허용 없이도 됩니다.
6. **정지**: 빨간 버튼, 또는 창 어디서나 `Space` / `Esc`.

## 그리퍼 (RH-P12-RN(A))
- 연결 경로: PC → ROS `drl_start` → 두산 컨트롤러가 DRL 실행 → 손목 RS-485 → 그리퍼. PC에 USB(U2D2)로 연결하는 ROBOTIS ROS 패키지 방식이 **아닙니다**.
- 그리퍼 설정: **Modbus RTU, 57600 bps, ID 1** (2026-11-07 실측). 라벨은 `RH-P12-RN`이지만 펌웨어는 (A) 버전(모델 35074, V15).
- 위치: `0` = 완전히 열림, `740` = 닫힘(손가락이 맞닿음). 화면은 740보다 큰 값은 보내지 않습니다.
- 잡는 힘 = 목표 전류(Goal Current). 그리퍼 한계는 661 mA. 전류가 0이면 움직이지 않습니다.
- 명령 하나에 2~6초 걸립니다(DRL 프로그램 실행 + 손가락 이동). 그동안 팔 버튼은 꺼집니다.
- 그리퍼 값은 자동으로 갱신되지 않습니다. 명령이 끝날 때와 `상태 읽기`를 누를 때 갱신됩니다.
- **정지 버튼은 그리퍼 프로그램을 중단하지만, 이미 보낸 손가락 목표는 그리퍼가 끝까지 수행할 수 있습니다.** 힘이 목표 전류로 제한되므로 약한 힘부터 쓰세요.
- `힘 풀기`는 토크를 끕니다. 잡고 있던 물건이 떨어질 수 있습니다.
- 그리퍼가 응답하지 않으면(기록 창에 "그리퍼가 응답하지 않음") `재접속`을 누르세요. `상태 읽기`는 실패하면 한 번 자동으로 다시 시도합니다. 57600 bps 이외의 속도로 시험한 뒤 손목 시리얼이 멈췄다가 재접속으로 풀린 적이 있습니다.
- 펜던트에서 직접 확인용 읽기 전용 DRL: `drl/rh_p12_comm_test.drl.py` (펜던트 Task Writer의 Custom Code에 붙여 넣기)

## 안전 장치 (코드에 들어 있음)
| 장치 | 내용 |
|---|---|
| 조작 잠금 | `조작 허용`을 체크해야 버튼이 동작, 2분 동안 명령이 없으면 자동으로 잠금 |
| 한 번에 하나 | 이동 중에는 버튼이 꺼지고, 다음 명령은 거부 |
| 상태 확인 | 로봇이 `대기(STANDBY)`이고 관절 각도가 0.5초 안에 들어왔을 때만 이동 |
| 크기·속도 상한 | 관절은 한 번에 10°·30°/s, 좌표는 20 mm·50 mm/s를 넘지 않음 |
| 관절 한계 | E0509 한계에서 5°를 뺀 범위 (J3 ±150°, 나머지 ±355°) |
| 최저 높이 | 손끝 Z가 `--z-min`(기본 50 mm)보다 내려가는 이동은 거부 |
| 절대 목표 | 매번 현재 위치를 새로 읽고, 거기에 작은 값만 더한 목표를 보냄 |
| 정지 | 비동기 이동이라 움직이는 중에도 정지 명령이 바로 들어감 (서보는 켜진 채 감속 정지) |
| 이름 분리 | 실제 로봇은 `/e0509_real`. 시뮬레이션 스크립트(`/dsr01/...`)가 닿지 않음 |
| 접속 확인 창 | 접속·끊기·재접속은 확인 창에서 `Yes`를 눌러야 실행. 끊기·재접속 중에는 모든 이동 버튼이 꺼지고 `조작 허용`이 풀림 |
| 팔·그리퍼 배타 | 팔 이동과 그리퍼 명령은 같은 잠금을 써서 동시에 실행되지 않음 |
| 그리퍼 한계 | 위치 0~740, 전류 ≤ 661 mA, 속도 ≤ 2970으로 잘라서 보냄. 손가락은 `조작 허용`일 때만 |

이 프로그램의 정지 버튼은 **비상정지를 대신하지 않습니다.** 실제 로봇을 움직일 때는 항상 비상정지 버튼 옆에 사람이 있어야 합니다.

## 검증 (2026-11-07)
- 에뮬레이터(DRCF 3.2.0)에서 15개 항목: J6 ±5°, Z ±10 mm(X/Y 변화 0.00 mm), 이동 중 두 번째 명령 거부, 이동 중 정지(10° 중 2.8°에서 멈춤), 크기 상한(50° 요청 → 10°), J3 한계 거부, 최저 높이 거부 — 모두 통과
- 화면 시험 7개: 잠금 상태에서 버튼 무반응, `+` 버튼으로 5° 이동, `Space`로 정지 — 모두 통과
- 실제 로봇(DRCF 2.10.3): 화면 연결과 값 표시만 확인. 이 프로그램으로 실제 로봇을 움직여 본 적은 아직 없음
- 그리퍼 DRL: 모의 그리퍼로 12개 시험 통과(상태 읽기, 쓰기 순서, 값 상한, 무응답, 토크 켜진 상태 보호 등)
- 접속 버튼 실기(손가락·팔 움직임 없음): 외부 bringup 찾아서 끊기, 접속 → 그리퍼 자동 읽기, 재접속 → 그리퍼 다시 읽기, 끊기, 두 번째 접속 거부 — 9/9 통과. 화면 버튼으로 같은 순서 9/9 통과. `ros2 launch` 후 Ctrl-C → 접속까지 정상 종료
- 그리퍼 실기: 상태 읽기, 그리고 토크를 끈 채 목표 전류·속도·위치를 쓰고 다시 읽어 일치 확인(손가락 움직임 없음). 그리퍼 명령 뒤 로봇은 `대기` 상태로 돌아옴. **손가락을 실제로 움직여 본 적은 아직 없음**

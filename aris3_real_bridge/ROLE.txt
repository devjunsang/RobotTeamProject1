ARIS3 / aris3_real_bridge
=========================

[폴더 역할]
실물 E0509 브리지 - 로봇 접속·이동·그리퍼·복구, 카메라 보정, 카메라 기반 집기 순서를 ROS 인터페이스로 내놓는다.
두 GUI(aris3_gui PyQt, aris3_gui_cpp ARIS C++ Qt)는 로봇에 직접 붙지 않고 이 노드만 부른다.

[개발 기술]
Python / rclpy (액션 서버·서비스), e0509_manual (RobotLink, bringup), OpenCV·NumPy (보정)

[구현할 내용]
/aris3/real/state (RealRobotState 10 Hz), /aris3/real/{connect,disconnect,stop} (Trigger),
/aris3/real/{set_armed,set_hand_guide} (SetBool), /aris3/real/calibration (RealCalibration),
/aris3/real/motion (RealMotion 액션), /aris3/real/pick_place (RealPickPlace 액션). 취소 = 정지.

[완료 기준]
GUI 를 꺼도 이 노드만으로 실물 집기·놓기를 실행할 수 있고, 두 GUI 가 같은 안전 코드(RobotLink)를 쓴다.

[원칙]
- 로봇 안전 코드(이동 전 검사, 도착 확인, 정지, 그리퍼 토크 확인, 복구)는 새로 짜지 않는다: e0509_manual RobotLink 그대로.
- 조작 허용(armed)을 이 노드도 가진다: 꺼져 있으면 이동·그리퍼·집기 요청 거부, 120 s 명령이 없으면 자동 잠금.
  GUI 의 「조작 허용」 과 이중 장치. 정지는 armed 와 상관없이 언제나 받는다 (별도 콜백 그룹).
- 확인창(사람 확인)은 GUI 몫이다. 이 노드는 받은 요청을 검사해 실행하거나 거부한다.

[개발 단계]
CHALLENGE (Qt GUI 전환 1단계, 2026-11-10)

[현재 상태]
1차 구현 (2026-11-10): 노드·launch·단위 시험. real_pick.py 를 aris3_gui 에서 옮김 (PyQt GUI 는 아직 이 파일을
직접 import 해서 예전처럼 동작 - 다음 단계에서 브리지 호출로 바꾼 뒤 실물 재시험).
실물 로봇으로는 아직 시험 전.
집기 보정 (2026-11-13): 그리퍼 각도 맞추기(J6, 집기 큐브 면 / 놓기 팔 방향 / 쌓기 받침), 쌓인 큐브 원근 보정 픽셀(grasp_u/v),
올려놓기 (2026-11-14): RealPickPlace PLACE_ON - 집지 않고 지금 들고 있는 큐브를 받침 큐브 위에 놓는다 (PickSequence.place_on).
닿는 거리 (2026-11-14): 베이스에서 reach_max_mm (기본 700) 보다 먼 큐브·놓을 자리는 출발 전에 거부하고, 컨트롤러가
  가까운 쪽: reach_min_mm (기본 300) 보다 가까우면 「너무 가까운 위치」 로 거부. 실물에서 약 210 mm 는 집는 높이로 내려가다
  「Joint Axis 3 angle beyond max limit (137.5° > 135°)」 로 멈췄고 428 mm 는 됐다 - 300 은 그때 관절 각도로 어림한 값.
  NOT REACHABLE 로 거부한 순서도 결과 문장에 「닿지 않는 위치」 를 넣는다 (ARIS 가 그 말을 보고 음성으로 알림).
  실물: 686 mm 는 갔고 716 mm 는 거부됨 (접근 높이 Z 245 mm, 그리퍼 아래 방향).
  받침은 쌓기처럼 지금 검출에서 다시 찾고(안 보이면 거부), 빈손이면 거부. 단위 시험만 - 실물은 아직.
접근 높이에서 큐브 중심 다시 재기. 파라미터 align_yaw·center_grasp 로 끔. 단위 시험 + 가상 컨트롤러 자체 시험, 실물은 HOVER 로 먼저 확인.
탁자 블록 마커 보정 (2026-11-14): 보정 ① 이 블록 윗면 ArUco 4X4_50 마커 중심(+ 깊이로 블록 높이·3D 점)을 씀
(marker_calib.py). 블록이 큐브와 높이가 다르면 픽셀·Z 를 큐브 높이로 고침. 블록 자동 기록(AUTO_RECORD): 로봇이 블록을
잡아 두 번 닫아 가운데 맞춘 TCP + 홈에서 다시 잰 마커 픽셀 -> 자동 보정점, 「보정 저장」 으로 새 보정. 합성 장면 단위 시험만.

# ARIS 명령어 사용법

ARIS(`aris3_gui_cpp`)에서 지금 쓸 수 있는 명령을 한곳에 모았습니다. 음성, 손짓, 화면 클릭, 키보드, 실행 옵션 순서입니다. (2026-11-13 기준)

> **안전 먼저.** 로봇을 움직이는 모든 명령은 화면의 **「조작 허용」 체크가 켜져 있어야** 실행됩니다.
> 조작 허용은 음성으로 켜지지 않습니다. 사람이 로봇 주변을 보고 직접 체크합니다(2분 동안 명령이 없으면 잠김).
> 음성 「멈춰」는 인식까지 약 1초가 걸립니다. **비상정지를 대신하지 않습니다.**

---

## 1. 음성 명령

화면의 **「음성 명령 모드」** 버튼을 켜고, **「아리스」로 부른 뒤** 말합니다.

- 한 번에: 「아리스, 노란 큐브 잡아」
- 나눠서: 「아리스」 → (ARIS: 「네, 말씀하세요.」) → 8초 안에 「노란 큐브 잡아」
- 「아리스」로 시작하지 않는 말은 무시합니다. 옆 사람과의 대화로 로봇이 움직이지 않게 하려는 것입니다.
- 음성으로 시작한 명령은 확인창 없이 바로 실행합니다. 조작 허용 검사는 그대로입니다.

### 1.1 명령 목록

| 말하기 (예) | 하는 일 | ARIS 대답 |
|---|---|---|
| 아리스, **노란 큐브 잡아** / 빨간 거 집어줘 / 파란색 들어 | 카메라에 보이는 그 색 큐브를 집기 | 네, 노란색 큐브를 잡습니다. |
| 아리스, **이거 잡아** | 화면에서 고른 큐브 집기 | 네, 고르신 물체를 잡습니다. |
| 아리스, **이거 저기로 옮겨** | 고른 큐브를 집어 고른 자리에 놓기 | 네, 고르신 물체를 집어서 고르신 자리로 옮깁니다. |
| 아리스, **노란 큐브를 파란 큐브 위로 옮겨줘** / 파란 거 위에 빨간 거 올려 / 노란 거 초록 큐브에 쌓아 | 앞의 큐브를 집어 받침 큐브 **위에 쌓기** (2중 명령) | 네, 노란색 큐브를 파란색 큐브 위에 올립니다. |
| 아리스, **이거 파란 큐브 위에 올려** | 화면에서 고른 큐브를 파란 큐브 위에 쌓기 | 네, 고르신 물체를 파란색 큐브 위에 올립니다. |
| 아리스, **저기 놔줘** (들고 있을 때) | 고른 자리에 내려놓기 | 네, 고르신 자리에 내려놓겠습니다. |
| 아리스, **내려놔** | 지금 위치 바로 아래에 내려놓기 | 네, 여기에 내려놓겠습니다. |
| 아리스, **홈으로** / 원위치 / 처음 자세로 | 홈 자세 [0, 0, 90, 0, 90, 0]° | 네, 홈 자세로 돌아갑니다. |
| 아리스, **그리퍼 열어** / 손 펴 / 집게 벌려 | 팔은 그대로 두고 그리퍼만 열기 (들고 있던 큐브는 그 자리에서 떨어짐). 「그리퍼·손·집게」 없이 「열어」 만은 받지 않음 | 네, 그리퍼를 엽니다. |
| 아리스, **멈춰** / 정지 / 그만 / 스톱 | 즉시 정지 | 네, 멈춥니다. |
| 아리스, **계속해** / 이어서 해 | 「멈춰」로 끊긴 집기를 멈춘 단계부터 이어서 | 네, 이어서 하겠습니다. |
| 아리스, **가동** / 깨어나 / 일어나 | 접속 후 팔을 위로 일자로 펴기(모든 관절 0°) | 네, 가동합니다. |
| 아리스, **연결해제** / 연결 끊어 | 로봇 접속 끊기 (서보 꺼짐, 브레이크가 팔을 잡음) | 네, 연결을 해제합니다. |

- 색: 빨간색, 파란색, 노란색, 초록색. 「빨간 거 말고 파란 거」처럼 말해도 실제로 집을 색(파랑)으로 읽습니다.
- 「가동」 자세는 손목이 특이 자세(J5 = 0°)라서, **집기 전에는 「아리스, 홈으로」** 를 먼저 합니다.
- **쌓기**: 「위」 바로 앞에 말한 색이 받침입니다. 그래서 「노란 걸 파란 거 위에」와 「파란 거 위에 노란 걸」은 같은 명령입니다. 두 색 모두 카메라에 **하나씩만** 보여야 하고, 놓는 높이는 받침 층 수 x 큐브 높이만큼 높습니다(실물 4 cm, 시뮬레이션 5 cm, 여유 5 mm). 받침 큐브는 움직이기 직전에 다시 찾고, 안 보이면 하지 않습니다. 실물 모드(시뮬레이션 포함)에서만 됩니다.
  - 위쪽 D455 깊이로 몇 층인지 재므로(2026-11-13~14), 쌓인 큐브 맨 위를 집거나 이미 쌓인 큐브 위에 더 올릴 수 있습니다(4층까지). 쌓인 큐브는 원근 보정한 위치로 집고, 그리퍼는 큐브(받침) 각도에 맞춰 돌립니다. 아래 큐브의 색은 모릅니다(위에서 맨 위만 보임). 자세한 것은 [실물 집기·보정 기능](ARIS3_실물_집기_보정_기능.md).
- **가려진 색 찾기**: 말한 색(집을 큐브·받침 큐브)이 카메라에 하나도 안 보이면, 로봇 팔에 가렸다고 보고 ARIS가 「파란색 큐브가 안 보여서 팔을 옆으로 움직여 찾아볼게요.」라고 말합니다. 그다음 몸통(J1)을 **천천히(약 7°/s) 10°씩** 시작 자세 기준 +20° → +40° → −20° → −40° → 0° 로 돌리며, 멈출 때마다 카메라를 봅니다.
  - 찾으면 「찾았어요.」 하고 원래 명령을 그 자리에서 이어서 합니다. 끝까지 못 찾으면 시작 자세로 돌아와 「찾아봤지만 … 보이지 않아요.」라고 말합니다.
  - 찾는 중에 「아리스, 멈춰」·STOP·Space 를 하면 바로 그만둡니다. 조작 허용이 꺼져도 그만둡니다. 찾는 중에 다른 명령은 받지 않습니다(「지금은 다른 작업을 하고 있어요.」).
- 「계속해」는 「멈춰」로 끊긴 경우만 됩니다. 그 사이 다른 동작을 하면 이어 하기는 잊습니다.

### 1.2 못 할 때 ARIS가 하는 말

| ARIS 대답 | 뜻 · 할 일 |
|---|---|
| 조작 허용을 먼저 켜 주세요. | 화면의 「조작 허용」을 체크 |
| 아직 움직일 준비가 되지 않았어요. | 접속 중이거나 로봇 상태가 대기가 아님. 상태 표시 확인 |
| 카메라 보정이 아직 없어요. | 실물 집기 패널에서 보정 불러오기 |
| 카메라에 노란색 큐브가 보이지 않아요. | 그 색 큐브가 카메라에 안 보임 |
| 노란색 큐브가 여러 개 있어요. 화면에서 하나를 골라 주세요. | 큐브를 클릭하고 「아리스, 이거 잡아」 |
| 파란색 큐브가 여러 개라 어느 위에 올릴지 모르겠어요. | 쌓기의 받침 색이 여러 개. 하나만 남기기 |
| 올릴 물체와 받침 큐브가 같아요. | 고른 큐브가 받침 큐브임. 다른 큐브를 고르기 |
| 파란색 큐브가 안 보여서 팔을 옆으로 움직여 찾아볼게요. | 팔에 가려진 색을 찾는 중 (멈추려면 「아리스, 멈춰」) |
| 찾아봤지만 파란색 큐브가 보이지 않아요. | 좌우로 돌려 봐도 없음. 큐브가 카메라 시야에 있는지 확인 |
| 팔을 더 돌릴 수 없어서 찾기를 멈췄어요. | 관절 한계 등으로 J1 이 움직이지 않음 |
| 어떤 물체인지 화면에서 먼저 골라 주세요. | 「이거」라고 했는데 고른 큐브가 없음 |
| 놓을 자리를 화면에서 먼저 골라 주세요. | 빈 곳을 클릭하고 다시 |
| 지금은 다른 작업을 하고 있어요. | 집기 순서 진행 중이거나 확인창이 떠 있음 |
| 잘 못 알아들었어요. 다시 말씀해 주세요. | 명령으로 읽지 못함. 또박또박 다시 |

### 1.3 잘 알아듣게 하려면

- 「아리스」와 명령 사이를 너무 길게 띄우지 않습니다(8초 안).
- 말을 마치면 0.8초쯤 조용히 기다립니다. 그때 말 한 마디가 끝난 것으로 봅니다.
- 음성 인식이 글자를 조금 틀려도 Claude Haiku가 소리로 고쳐 읽습니다. 예: 「혐의로」→홈으로, 「먹쳐」→멈춰, 「노란색 큐구 자바」→노란 큐브 잡아.
- ARIS가 말하는 중에도 「아리스, 멈춰」는 들립니다.
- 인터넷이 끊기면 낱말 표 해석기로 바뀝니다. 이때는 위 표의 낱말 그대로 말하는 것이 좋습니다.
- 마이크 없이 시험하려면 음성 패널 입력칸에 문장을 치고 「해석」을 누릅니다(호출어 없어도 됨).

## 2. 손짓 (실물 위쪽 카메라 · MediaPipe)

카메라 아래 작업대 위에서 손으로 합니다. 손짓으로 시작한 동작은 **확인창**을 띄웁니다.

| 손짓 | 하는 일 |
|---|---|
| ☝ 검지로 가리키고 **1초 멈춤** | 그곳을 고름. 큐브 위면 집을 큐브(이거), 빈 곳이면 놓을 자리(저기) |
| ☝ 가리킴 → ✊ **주먹** | 고른 큐브 집기 |
| ☝ 가리킴 → ✋ **손바닥 펼침** | 고른 자리에 놓기 |

- 멈춤 판정: 1초 동안 손끝이 25픽셀 안에 있어야 합니다.
- 확인창이 떠 있는 동안 들어온 손짓은 무시합니다.

## 3. 화면 조작

### 3.1 카메라 화면 클릭

- **큐브를 클릭** → 집을 큐브로 고름(이거). 클릭한 곳에서 4 cm 안의 가장 가까운 큐브를 고릅니다.
- **빈 곳을 클릭** → 놓을 자리로 고름(저기).
- 순서는 상관없습니다. 고른 뒤 버튼이나 「아리스, 이거 저기로 옮겨」로 실행합니다.

### 3.2 주요 버튼

| 버튼 | 하는 일 |
|---|---|
| Connect / Disconnect | 로봇(또는 가상 컨트롤러) 접속 / 끊기 |
| ⌂ Home | 홈 자세 |
| 조작 허용 체크 | 움직이는 명령을 허용 (2분 동안 명령이 없으면 잠김) |
| 큐브 위로 · 집기 · 놓기 · 집어서 옮기기 | 고른 큐브·자리로 실물 집기 순서 (매번 확인창) |
| 블록 자동 기록 (로봇이 잡아서) | 마커 붙인 블록을 탁자에 두고 누르면 로봇이 블록을 잡아(손목 90° 돌려 두 번) 가운데 맞춘 위치를 기록하고 홈에서 마커를 다시 잼. 블록 자리를 바꿔 6~8번 후 「보정 저장」 = 새 보정 (예전 파일 백업) |
| ① 마커·큐브 픽셀 기억 → ② 로봇 위치 기록 | 카메라 보정. ArUco 4X4_50 (ID 0) 마커를 붙인 블록을 탁자에 두고 ①, 그리퍼를 그 블록을 집는 자세로 내리고 ②. 자리를 바꿔 6~8번 후 「보정 저장」. 마커가 없으면 화면에서 고른 큐브로 |
| 복구 홈 | 안전 정지 해제 → 서보 켜기 → 자동 모드 → 홈 |
| 손으로 움직이기 | 수동 모드. 팔 끝 콕핏의 직접 교시 버튼을 누른 채 팔을 끌어 옮김 (보정 점 찍기) |
| 수동 조작 (TCP·Joint 조그) | 한 축씩 조금씩 이동 |
| **STOP** | 즉시 정지 |

### 3.3 키보드

| 키 | 하는 일 |
|---|---|
| **Space** · **Esc** | 즉시 정지 (어느 창에 있든). 문장 입력칸에 글을 치는 중이면 Space는 띄어쓰기 |

## 4. 실행 명령 (터미널)

```bash
source ~/ros2_ws/install/setup.bash
ros2 run aris3_gui_cpp aris
```

- 실물 로봇(110.120.1.66:12345)이 1.5초 안에 응답하면 **실물**, 아니면 **시뮬레이션**으로 시작합니다. 시뮬레이션이면 ARIS가 Gazebo 월드를 직접 띄웁니다.
- 창이 열리면 **접속 → 조작 허용 → 홈 자세**까지 저절로 갑니다. 실물이면 접속 전에 확인창을 한 번 띄웁니다.
- Haiku 해석에는 `ANTHROPIC_API_KEY` 환경 변수가 필요합니다(`~/.bashrc`에 넣어 둠). 없으면 낱말 표 해석기만 씁니다.

| 옵션 | 뜻 |
|---|---|
| `--sim` | 실물 로봇이 있어도 시뮬레이션으로 |
| `--no-auto-home` | 창이 열려도 자동으로 접속·홈 하지 않음 |
| `--no-voice` | 음성 노드를 띄우지 않음 |
| `--no-gesture` | 손짓 노드를 띄우지 않음 |
| `--host 110.120.1.66` | 실물 컨트롤러 주소 |
| `--z-min 50` | 집기 최저 높이 [mm] (이보다 낮게 내려가지 않음) |
| `--mode sim` | 예전 MoveIt 시뮬레이션 모드 |
| `--mode real --sim --selftest` | 실물 경로 자체 시험 7단계 (가상 컨트롤러) |

ARIS 창을 닫으면 ARIS가 띄운 브리지, 음성, 손짓, 시뮬레이션 월드도 같이 꺼집니다.

## 5. 기록(로그) 보는 곳

| 무엇 | 어디 |
|---|---|
| ARIS 화면 로그 | 화면 아래 LOGS 패널 (「ARIS 로그만」 체크로 거르기) |
| 음성 (Whisper가 적은 글자, 해석기, ARIS가 한 말) | `/tmp/aris_voice.log` |
| 실물 브리지 | `/tmp/aris_real_bridge.log` |
| 시뮬레이션 월드 | `/tmp/aris_sim_world.log` |
| 손짓 | `/tmp/aris_gesture.log` |

말을 자꾸 못 알아들으면 `/tmp/aris_voice.log`에서 「아리스 혐의로」처럼 Whisper가 실제로 적은 글자를 먼저 보세요.
